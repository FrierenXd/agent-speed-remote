# Remote Agent Statistics / 远程 Agent 统计

- Monitor Agent activity on Linux, macOS and Windows hosts over verified SSH.
- Switch between local statistics, one remote host, or all hosts; view live rates, token usage, costs and daily history.
- **Auto-deploy & connect / update** detects the remote OS/architecture, uploads the bundled collector, verifies SHA-256 and checks the runtime before connecting. No manual upload, root access or remote .NET installation required.
- Automatic reconnection, isolated history caches, bounded protocol input and strict SSH host-key checks.
- Application updates and installer scripts use this fork's releases, preserving remote monitoring support.

## macOS 下载与使用

下载 **AgentSpeed-macOS.zip**，解压后将 **Agent Speed.app** 拖入「应用程序」。
支持 **macOS 14+，Apple Silicon 和 Intel 通用版**。

本构建使用 ad-hoc 签名，未经过 Apple Developer ID 公证。首次打开若被 Gatekeeper 阻止，
请确认来源与 `SHA256SUMS.txt` 校验值，然后在「系统设置 → 隐私与安全性」中允许打开。

在「设置 → 数据源 → 远程主机」填写 SSH 目标，点击「自动部署并连接 / 更新」。
须先在终端核验服务器指纹、配置 SSH 密钥登录；Linux 目标需 glibc 与系统 SQLite/ICU/OpenSSL。
详细说明：[远程配置与部署指南](https://github.com/FrierenXd/agent-speed-remote/blob/main/docs/REMOTE.md)。

仅传统计，不传对话或项目路径。流量统计与排行榜实时上报仍仅限桌面本机。
远程响应通知暂不转发。安装脚本与应用内更新均指向本仓库。
